
# Virtuālā izstāde — Pastaiga cauri kosmosam

## 1. Projekta apraksts

Projekts izstrādāts PB1 praktisko mācību “Programmas koda rakstīšana (Kodēšana)” ietvaros. Tā mērķis ir izveidot virtuālu izstādi par kosmosa izpēti un zinātniskajiem atklājumiem.

- **Izstādes tēma:** Kosmoss un zinātniskie atklājumi
- **Izstādes nosaukums:** Pastaiga cauri kosmosam

Tīmekļa vietnē apkopoti seši nozīmīgi kosmosa izpētes notikumi, trīs neatbildēti jautājumi par kosmosu, astoņu kosmosa objektu attēlu galerija un piecu attēlu karuselis.

## 4. Izmantotās tehnoloģijas

- **HTML5** — tīmekļa vietnes struktūrai un satura organizēšanai.
- **CSS3** — vizuālajam noformējumam, Box Model, Flexbox, Grid un responsīvajam dizainam.
- **JavaScript** — attēlu karuseļa vadībai un galerijas attēlu ielādei no `gallery.md`.
- **Marked.js** — Markdown satura parsēšanai.
- **Git un GitHub** — projekta versiju kontrolei un komandas sadarbībai.
- **Visual Studio Code** — projekta izstrādes videi.

## 5. Tīmekļa vietnes funkcionalitāte

- Galvene ar navigāciju uz galvenajām sadaļām.
- Izstādes ievads un informācija par kosmosu.
- Sešu kosmosa izpētes atklājumu hronoloģija.
- Trīs sadaļas par vēl neatrisinātiem kosmosa jautājumiem.
- Attēlu galerija ar astoņiem kosmosa objektiem un to aprakstiem.
- Attēlu karuselis ar pieciem attēliem un paskaidrojumiem.
- Karuseļa manuāla pārslēgšana ar pogām un indikatoriem.
- Automātiska attēlu pārslēgšana ar iespēju to apturēt un atsākt.
- Responsīvs izkārtojums dažādiem ekrāna izmēriem.
- Kājene ar komandas un autortiesību informāciju.

## 6. Projekta palaišana

1. Lejupielādējiet projekta failus vai klonējiet GitHub repozitoriju.
2. Atveriet projekta mapi Visual Studio Code.
3. Palaidiet `index.html` ar lokālo tīmekļa serveri, piemēram, Visual Studio Code paplašinājumu **Live Server**.
4. Pārlūkprogrammā atveriet servera norādīto adresi.

Projektam nepieciešama šāda failu struktūra:

```text
projekts/
├── index.html
├── script.js
├── gallery.md
├── css/
│   └── style.css
└── images/
    └── attēlu faili
```
